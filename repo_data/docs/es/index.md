# Documentación de ParsiKit

Bienvenido a la documentación oficial de **ParsiKit** en español.

ParsiKit es una biblioteca de infraestructura de datos en Python puro de alto rendimiento, diseñada específicamente para el procesamiento, normalización, validación y cálculos del idioma persa (farsi) y los estándares de datos de Irán.

---

## Características Principales

- **Python Puro**: Cero dependencias externas. Compatible con Python 3.10+.
- **Normalización de Texto**: Corrección de caracteres arábigos a persas, manejo preciso del espacio de no separación de ancho cero (ZWNJ / نیم‌فاصله) y limpieza de diacríticos.
- **Validación y Checksums**: Algoritmo Módulo 11 para Código Nacional Iraní, algoritmo de Luhn para tarjetas bancarias y validación de IBAN (Sheba).
- **Calendario Jalalí (Hégira Solar)**: Conversión astronómica de fechas con cálculo exacto del ciclo bisiesto de 33 años.
- **Cálculos Financieros**: Conversiones entre Riales y Tomanes, cálculo del IVA (ارزش افزوده) y conversión de números a palabras en persa.
- **Seguridad de Datos**: Enmascaramiento de datos personales identificables (PII) como teléfonos móviles, tarjetas bancarias y números de cuenta.
