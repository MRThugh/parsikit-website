# Саволҳои маъмул (FAQ)

Дар ин саҳифа посух ба саволҳои асосӣ пешниҳод мегардад.

---

## 1. Оё ParsiKit ба китобхонаҳои беруна ниёз дорад?

Не. ParsiKit бар пояи принсипи **бе вобастагӣ (Zero Dependencies)** сохта шудааст ва 100% бо Python-и холис кор мекунад.

---

## 2. Бо кадом нусхаҳои Python мутобиқ аст?

Аз Python 3.10 ва нусхаҳои навтар (3.11, 3.12, 3.13) комилан пуштибонӣ мешавад.

---

## 3. Тақвими шамсӣ чӣ тавр ҳисоб карда мешавад?

Ҳисоботҳо бар асоси даври 33-солаи нуҷумии ҳиҷрии шамсӣ анҷом дода мешаванд, ки дақиқтарин модели тақвимӣ мебошад.
