# Роҳнамои расмии китобхонаи ParsiKit

Ба маркази ҳуҷҷатгузорӣ ва роҳнамоҳои китобхонаи **ParsiKit** хуш омадед.

ParsiKit як китобхонаи мустақил, боэътимод ва сабук дар забони Python (3.10+) мебошад, ки бидуни ниёз ба вобастагиҳои беруна (Zero Dependencies), маҷмӯаи васеи абзорҳоро барои коркард ва поксозии матн, санҷиши рақамҳои миллӣ ва кортҳои бонкӣ, тақвими шамсӣ ва ҳисоботи молӣ пешниҳод менамояд.
