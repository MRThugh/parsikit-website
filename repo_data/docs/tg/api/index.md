# Мундариҷаи расмии API (ParsiKit)

Ин саҳифа тамоми модулҳо, тавобеъ ва классҳои китобхонаи ParsiKit-ро дар бар мегирад.

---

## Модулҳо

| Модул | Вазифа ва шарҳ |
| :--- | :--- |
| `parsikit.text` | Поксозии матн, танзими нимафосилаҳо ва мутобиқсозии ҳарфҳо |
| `parsikit.validators` | Санҷиши чексам ва эътибори рақами миллӣ ва кортҳои бонкӣ |
| `parsikit.datetime` | Тақвими нуҷумии ҳиҷрии шамсӣ ва ҳисоби соли кабиса |
| `parsikit.currency` | Табдили ададҳо ба калимаҳо ва ҳисобҳои воҳидҳои пулӣ |
| `parsikit.models` | Моделҳои объектгаро бо санҷиши худкор |
| `parsikit.cache` | Кеши сареъ барои муҳити бисёрриштагӣ (Thread-safe LRU Cache) |
