# Моделҳои объектгаро (parsikit.models)

Классҳои моделӣ барои нигоҳдорӣ ва санҷиши худкори додаҳо.

---

## Классҳо

### `NationalCode`
Модели нигоҳдорандаи рақами миллӣ:
- `nc.formatted`: шакли ҷудошуда бо тире
- `nc.masked`: шакли амн бо ситорачаҳо
- `nc.clean`: сатри холиси рақамҳо

### `BankCard`
Модели корти бонкӣ:
- `card.is_valid`: вазъияти эътибор бо Лун
- `card.bank_name`: номи бонки интишоркунанда
- `card.masked`: рақами амни ниқоббаста
