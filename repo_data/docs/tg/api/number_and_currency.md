# Модули ҳисобҳои молӣ ва калимаҳо (parsikit.currency)

Табдили ададҳо ба калимаҳои хоно ва ҳисобҳои воҳидҳои пулӣ.

---

## Тавобеъ

### `number_to_persian_words(num: int) -> str`
Табдили ададҳо то 999 септиллион ба шакли лафзӣ.

### `format_currency(amount: int, unit: str = "toman") -> str`
Тартибдиҳии ададҳо бо ҷудокунии 3-рақама ва номи воҳиди пул.
