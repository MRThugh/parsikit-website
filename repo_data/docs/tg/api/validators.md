# Модули санҷиши эътибор (parsikit.validators)

Алгоритмҳои расмии тафтиши чексам ва шинохти додаҳои ҳувиятӣ.

---

## Тавобеъ

### `is_valid_national_code(code: str) -> bool`
Санҷиши дурустии рақами миллӣ бар асоси алгоритми расмии Модуло 11.

### `is_valid_card_number(card: str) -> bool`
Санҷиши эътибори корти бонкии 16-рақама бо алгоритми Лун (Luhn).

### `detect_bank_from_card(card: str) -> Optional[str]`
Муайян кардани номи бонки интишоркунанда аз рӯи 6 рақами аввал.

### `mask_card(card: str) -> str`
Ниқоббандии амни корти бонкӣ (мисол: `6037-9911-****-4455`).
