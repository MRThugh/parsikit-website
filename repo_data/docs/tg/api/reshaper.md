# Модули бозсозии графикӣ (`parsikit.reshaper`)

Абзори сабук ва бидуни вобастагӣ барои пайваст кардани ҳарфҳо (Cursive Shaping) ва баргардонидани самти матн (BiDi) барои муҳаррикҳои графикӣ, аксҳо ва бозиҳо.

---

## 1. Муаррифӣ ва ҳадафи техникӣ

Аксари муҳаррикҳои графикӣ дар Python (монанди Pygame, OpenCV, Pillow бидуни libraqm, китобхонаҳои эҷоди PDF ва муҳаррикҳои бозисозӣ) матнро аз чап ба рост чоп мекунанд. Дар натиҷа, ҳарфҳо ба сурати ҷудо-ҷудо ва чаппа намоиш дода мешаванд.

Модули `parsikit.reshaper` бо табдил додани аломатҳо ба шаклҳои муносиби матнии Юникод (ибтидоӣ, миёна, интиҳоӣ ва алоҳида) ва танзими самти калимаҳо ин мушкилотро бидуни ниёз ба китобхонаи иловагӣ ҳал мекунад.

---

## 2. Функсияҳои асосӣ

### Функсияи `reshape_for_graphics(text: str, reverse: bool = True) -> str`

Ҳарфҳоро ба якдигар мепайвандад ва дар сурати зарурат, самти онро барои муҳаррикҳои аз чап ба рост баргардонида (инверсия) месозад.

#### Параметрҳо:
- **`text`** (`str`): Матн ё ибораҳои дузабона.
- **`reverse`** (`bool`, пешфарз `True`): Агар `True` бошад, ҳарфҳоро барои муҳаррикҳои чап-ба-рост баргардон мекунад. Калимаҳои лотинӣ, рақамҳо, суроғаҳои интернетӣ ва почтаҳои электронӣ самти дурусти худро нигоҳ медоранд.

#### Натиҷа:
- `str`: Матне, ки барои намоиши графикӣ омода шудааст.

#### Мафҳуми самт ва инверсия:
- **`reverse=True` (Пешфарз):** Барои муҳаррикҳои оддӣ ба мисли Pygame ва OpenCV, ки расмкаширо аз тарафи чап сар мекунанд. Тартиби ҳарфҳо баргардон карда мешавад, аммо рақамҳо ва калимаҳои лотинӣ бетағйир мемонанд.
- **`reverse=False`:** Барои муҳаррикҳое, ки самти ҷараёни матнро идора карда метавонанд, вале қобилияти пайваст кардани ҳарфҳоро (font cursive shaping) надоранд. Дар ин ҳолат танҳо пайвасткунии ҳарфҳо анҷом мешавад.

#### Имкониятҳои фаннӣ:
- Пайваст кардани тамоми алифбо ва аломатҳои арабӣ (аз ҷумла `ۀ`, `ك`, `ي`).
- Таркиби худкори пайвасти ҳарфи Лом-Алиф (`لا`, `لآ`, `لأ`, `لإ`).
- Нигоҳ доштани аломатҳои эъробӣ баъд аз инверсияи самт.
- Ҷудосозии калимаҳои лотинӣ ва рақамҳо барои пешгирӣ аз вайроншавии тартиби хониш.

#### Мисоли амалӣ:

```python
import parsikit

raw_text = "Салом дунё (нусхаи 3.3.1)"

# Омодасозӣ барои Pygame ё Pillow
ready_text = parsikit.reshape_for_graphics(raw_text)

# Танҳо пайвасти ҳарфҳо бидуни инверсия
shaped_only = parsikit.reshape_for_graphics(raw_text, reverse=False)
```

---

### Функсияи `reshape_paragraph_for_graphics(text: str, max_chars_per_line: int, reverse: bool = True) -> list[str]`

Параграфи дарозро мутобиқи бари муайяншуда ба сатрҳо тақсим карда, ҳар сатрро барои кашидани графикӣ бозсозӣ менамояд.

#### Параметрҳо:
- **`text`** (`str`): Матн.
- **`max_chars_per_line`** (`int`): Шумораи ҳадди аксари аломатҳо дар як сатр.
- **`reverse`** (`bool`, пешфарз `True`): Фаъол будани инверсия барои муҳаррикҳои LTR.

#### Натиҷа:
- `list[str]`: Рӯйхати сатрҳои омодашуда.

#### Мисоли амалӣ:

```python
import parsikit

text = "ParsiKit китобхонаи сареъ ва мустақил барои коркарди додаҳо дар Python мебошад."
lines = parsikit.reshape_paragraph_for_graphics(text, max_chars_per_line=30)
for line in lines:
    print(line)
```
