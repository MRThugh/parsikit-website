# Модули кеши сареъ (parsikit.cache)

Модули `parsikit.cache` механизми кешкунии бисёрриштагӣ (Thread-safe LRU Cache)-ро таъмин менамояд.

---

## Хусусиятҳо

- Истифода аз модулҳои стандартии Python бе ниёз ба китобхонаҳои беруна
- Қулфбандии `threading.Lock` барои ҳифзи амнияти риштаҳо дар сервери веб
- Андозаи танзимшаванда (андозаи пешфарз: 1024)
