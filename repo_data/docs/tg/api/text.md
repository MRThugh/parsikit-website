# Модули коркарди матн (parsikit.text)

Тавобеи ин модул барои яксонсозии матн ва ислоҳи нимафосилаҳо мусоидат мекунанд.

---

## Тавобеи муҳим

### `standardize_persian(text: str) -> str`
Ҳарфҳои арабиро ба ҳуруфи стандартӣ табдил дода, фосилаҳои зиёдатиро ихтисор мекунад.

### `clean_text(text: str) -> str`
Поксозии куллӣ ва ҷойгузинии нимафосилаҳо дар пешвандҳо ва пасвандҳо.

### `slugify(text: str) -> str`
Сохтани URL slug бо тарҷумаи овоӣ ба алифбои лотинӣ.
