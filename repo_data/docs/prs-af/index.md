# رهنمودهای جامع کتابخانه پارسی‌کیت (ParsiKit)

به مرکز اسناد و رهنمودهای رسمی کتابخانه **پارسی‌کیت (ParsiKit)** خوش آمدید.

پارسی‌کیت یک کتابخانه معیاری، سریع و سبک در زبان پایتون (Python 3.10+) است که بدون هرگونه وابستگی بیرونی (Zero Dependencies)، ابزارهای همه‌جانبه‌ای را برای تصفیه متون زبان فارسی دری، تثبیت اعتبار شماره‌های هویت و تذکره، کارت‌های بانکی، تقویم هجری شمسی و محاسبات پولی در اختیار توسعه‌دهندگان نرم‌افزار قرار می‌دهد.
