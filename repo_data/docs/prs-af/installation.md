# رهنمود نصب و راه‌اندازی پارسی‌کیت

کتابخانه پارسی‌کیت کاملاً با پایتون خالص (Pure Python) نوشته شده و هیچ وابستگی به پکیج‌های خارجی یا کتابخانه‌های باینری ندارد. بنابراین در تمام سیستم‌های عامل (لینوکس، ویندوز و مک‌او‌اس) به سرعت و بدون مشکل نصب می‌شود.

---

## نیازمندی‌های سیستم

- پایتون نسخه **۳.۱۰** یا بالاتر (پشتیبانی مکمل از Python 3.10، 3.11، 3.12 و 3.13)
- بدون ضرورت به کامپایلر یا برنامه‌های جانبی

---

## ۱. نصب مستقیم از طریق pip

ساده‌ترین شیوه برای نصب آخرین نسخه پایدار از مخزن PyPI:

```bash
pip install parsikit
```

اگر از پکیج منیجرهای معاصر مانند Poetry یا uv استفاده می‌نمایید:

```bash
# نصب با Poetry
poetry add parsikit

# نصب با uv
uv add parsikit
```

---

## ۲. نصب مستقیم از سورس کد (GitHub)

برای نصب آخرین تغییرات از شاخه توسعه در گیت‌هاب:

```bash
git clone https://github.com/MRThugh/ParsiKit.git
cd ParsiKit
pip install .
```

برای نصب در حالت ویرایش همزمان (Editable Mode):

```bash
pip install -e .
```

---

## ۳. آزمایش نصب در محیط پایتون

برای اطمینان از صحت نصب، پایتون را در ترمینال باز نموده و دستورات ذیل را اجرا فرمایید:

```python
import parsikit

print(parsikit.__version__)
# خروجی باید '3.3.1' باشد
```
