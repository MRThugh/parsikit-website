# سیستم کش چندنخی (parsikit.cache)

ماژول `parsikit.cache` یک سیستم حافظه موقت امن در محیط‌های چندنخی (Thread-safe LRU Cache) فراهم می‌کند تا تبدیل‌های محاسباتی سنگین تکراری بدون افت عملکرد انجام شوند.

---

## ویژگی‌ها

- پیاده‌سازی با کلاس‌های استاندارد پایتون بدون نیاز به کتابخانه‌های سنگین
- بهره‌مندی از قفل انحصاری `threading.Lock` برای جلوگیری از Race Condition در سرورهای وب چندنخی (FastAPI، Django، Flask)
- محدودیت اندازه قابل تنظیم (maxsize پیش‌فرض: ۱۰۲۴ مورد)
