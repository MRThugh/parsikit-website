# ماژول اعتبارسنجی (parsikit.validators)

ماژول `parsikit.validators` الگوریتم‌های رسمی برای بررسی صحت داده‌های هویتی، مالی و مخابراتی را فراهم می‌سازد.

---

## توابع اعتبارسنجی

### `is_valid_national_code(code: str) -> bool`
بررسی صحت شماره هویت با الگوریتم پیمانه ۱۱.

### `is_valid_card_number(card: str) -> bool`
بررسی صحت شماره ۱۶ رقمی کارت بانکی با الگوریتم لان (Luhn Algorithm).

### `detect_bank_from_card(card: str) -> Optional[str]`
شناسایی خودکار بانک عامل صادرکننده کارت بانکی بر اساس ۶ رقم نخست.

### `mask_card(card: str) -> str`
ماسک‌کردن امن شماره کارت به فرمت استاندارد (مثال: `6037-9911-****-4455`).

### `mask_mobile(mobile: str) -> str`
مخفی‌سازی ارقام میانی شماره تماس به منظور رعایت حریم خصوصی.
