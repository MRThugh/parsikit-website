# ماژول پردازش متن (parsikit.text)

ماژول `parsikit.text` مجموعه‌ای از توابع کارآمد را برای پاکسازی و یکنواخت‌سازی متون زبان فارسی دری فراهم می‌آورد.

---

## توابع اصلی

### `standardize_persian(text: str) -> str`
کاراکترهای عربی مانند «ي» و «ك» را به حروف معیاری دری تبدیل کرده و فواصل نامناسب را فشرده می‌سازد.

### `clean_text(text: str) -> str`
پاکسازی همه‌جانبه شامل حذف اعراب غیرضروری، کنترل نیم‌فاصله‌ها و حذف کاراکترهای مخفی.

### `slugify(text: str) -> str`
تولید پیوندهای یکتا (URL Slug) با نویسه‌گردانی دقیق حروف به حروف لاتین (Pinglish).
