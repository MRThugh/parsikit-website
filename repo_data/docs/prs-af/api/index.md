# مرجع کامل توابع و کلاس‌های پارسی‌کیت (API)

این مستند فهرست جامع تمام ماژول‌ها، کلاس‌ها و توابع موجود در کتابخانه پارسی‌کیت را معرفی می‌نماید.

---

## ساختار ماژول‌ها

| ماژول | توضیح و کاربرد اصلی |
| :--- | :--- |
| `parsikit.text` | تصفیه متون، تنظیم نیم‌فاصله‌ها، حذف اعراب و معیارسازی حروف |
| `parsikit.validators` | اعتبارسنجی تذکره، کارت‌های بانکی، شبا، شناسه ملی و موبایل |
| `parsikit.datetime` | تقویم نجومی هجری شمسی، تبدیل تاریخ و محاسبه سال کبیسه |
| `parsikit.currency` | تبدیل ارقام به حروف، قالب‌بندی مالی و محاسبات ارزی |
| `parsikit.models` | مدل‌های داده‌ای شیءگرا با سازگاری Pydantic v2 |
| `parsikit.cache` | سیستم کش چندنخی (Thread-safe LRU Cache) |
| `parsikit.exceptions` | سلسله‌مراتب خطاهای اختصاصی و استاندارد |
| `parsikit.dev` | ابزارهای عیب‌یابی و محاسبه طول واقعی متون فارسی |
