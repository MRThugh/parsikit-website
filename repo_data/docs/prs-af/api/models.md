# مدل‌های شیءگرا (parsikit.models)

ماژول `parsikit.models` کلاس‌های داده‌ای غنی (Domain Models) را برای کپسوله‌سازی و اعتبارسنجی خودکار مقادیر فراهم می‌آورد.

---

## کلاس‌های موجود

### `NationalCode`
کلاس نگه‌دارنده شماره هویت و تذکره همراه با بررسی صحت خودکار در زمان ساخته‌شدن شیء:
- `nc.formatted`: فرمت تفکیک‌شده با خط تیره
- `nc.masked`: فرمت امن با ستاره
- `nc.clean`: رشته ارقام خالص
- `nc.province`: نام استان یا ولایت صادرکننده

### `BankCard`
کلاس داده‌ای کارت بانکی:
- `card.is_valid`: وضعیت درستی شماره با الگوریتم لون
- `card.bank_name`: نام بانک عامل صادرکننده
- `card.masked`: شماره ماسک‌شده امن

### `MobileNumber`
کلاس شماره تلفن همراه:
- `m.operator`: نام اپراتور شبکه مخابراتی
- `m.international`: فرمت بین‌المللی با کد کشور (+98 / +93)
