# آموزش تصفیه متن و نیم‌فاصله‌ها در زبان دری

در این آموزش گام‌به‌گام با نحوه استفاده از ابزارهای تصفیه متن و نیم‌فاصله‌ها در پارسی‌کیت آشنا می‌شوید.

---

## ۱. حذف کاراکترهای عربی ناخواسته

متون فارسی و دری که از کیبوردهای متفرقه یا پایگاه‌های داده وب جمع‌آوری می‌شوند اغلب دارای کاراکترهای عربی مانند «ي» با دو نقطه یا «ك» با همزه هستند:

```python
import parsikit

dirty = "اين يك متن آزمايشي است"
clean = parsikit.standardize_persian(dirty)
print(clean)
# خروجی: 'این یک متن آزمایشی است'
```

---

## ۲. تصحیح نیم‌فاصله‌های پیشوندی و پسوندی

کلمات دارای پسوند جمع («ها») یا پیشوند استمرار («می») نیازمند نیم‌فاصله (ZWNJ) هستند تا به درستی نگارش شوند:

```python
import parsikit

text = "کتاب ها را می خوانم"
corrected = parsikit.clean_text(text)
print(corrected)
# خروجی: 'کتاب‌ها را می‌خوانم'
```
