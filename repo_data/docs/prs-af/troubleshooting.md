# عیب‌یابی و رفع اشکالات متداول

راهکارهای حل اشکالاتی که ممکن است در جریان استفاده از پارسی‌کیت با آنها روبرو شوید.

---

## ۱. خطای `InvalidNationalCodeError`

این استثنا زمانی رخ می‌دهد که ورودی با استانداردهای چک‌سام پیمانه ۱۱ همخوانی نداشته باشد:

- اطمینان حاصل کنید که ارقام ورودی دقیقاً ۱۰ رقم باشند.
- ورودی نباید از ۱۰ رقم تکراری یکسان (مانند `1111111111`) تشکیل شده باشد.
- با استفاده از بلوک `try ... except` این خطا را به درستی مدیریت نمایید:

```python
from parsikit.exceptions import InvalidNationalCodeError
from parsikit.models import NationalCode

try:
    code = NationalCode("1234567890")
except InvalidNationalCodeError as e:
    print(f"شماره هویت نامعتبر است: {e}")
```

---

## ۲. خطای `InvalidCardNumberError`

این خطا ناشی از عدم تطابق شماره کارت با الگوریتم لون (Luhn Checksum) است:

- شماره کارت باید ۱۶ رقم باشد.
- فواصل و خط فاصله‌ها به صورت خودکار توسط متدها حذف می‌شوند.

---

## ۳. عدم نمایش صحیح متون دارای نیم‌فاصله در ترمینال

بعضی از ترمینال‌های قدیمی کاراکتر نیم‌فاصله (ZWNJ) را به شکل نامرئی یا با فاصله نادرست ترسیم می‌کنند. برای نمایش دقیق در کنسول می‌توانید از متدهای موجود در ماژول `parsikit.dev` جهت تراز بصری متن‌ها استفاده کنید.
